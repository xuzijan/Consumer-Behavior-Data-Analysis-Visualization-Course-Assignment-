ipynb文件进行简单的单指标分析
### 1. **客户人口统计学分析**

- 年龄分布分析（年龄段偏好）
- 性别购买行为差异
- 年龄与性别的交叉分析
- 不同年龄段的消费能力分析

### 2. **商品类别与偏好分析**

- 商品类别销量分布
- 不同性别对商品类别的偏好
- 季节性商品购买趋势
- 商品尺寸分布规律
- 颜色偏好分析

### 3. **消费行为分析**

- 购买金额分布情况
- 不同年龄段的平均消费水平
- 性别与消费金额的关系
- 历史购买次数与当前消费的关联

### 4. **地理分析**

- 各州销量分布热力图
- 地区消费偏好差异
- 不同地区的平均消费水平

### 5. **季节性分析**

- 四季销量变化趋势
- 季节与商品类别的关系
- 季节性颜色偏好
- 季节对消费金额的影响

### 6. **客户满意度分析**

- 评价评分分布
- 评分与商品类别的关系
- 评分与消费金额的关联
- 不同购买频率客户的满意度

### 7. **营销策略效果分析**

- 折扣使用情况及其对销量的影响
- 促销代码使用率分析
- 订阅客户 vs 非订阅客户行为差异
- 不同支付方式的使用偏好

### 8. **物流配送分析**

- 配送方式选择偏好
- 配送方式与消费金额的关系
- 不同地区的配送方式选择

### 9. **客户忠诚度分析**

- 购买频率分布
- 历史购买次数分析
- 忠诚客户的特征画像
- 购买频率与消费金额的关系

### 10. **综合关联分析**

- 多维度交叉分析（年龄-性别-类别-季节）
- 客户行为模式聚类
- 消费者画像构建
- 商品推荐相关性分析

python文件利用streamlit进行进一步指标关联分析

geo_advanced_dashboard.py
高级地理可视化分析仪表盘。
支持按性别、类别、季节筛选数据，动态展示美国各州销量热力图。
实现地区客户聚类分布（KMeans）、州级画像钻取、商品推荐网络流向图（NetworkX）、多维雷达对比。
亮点：地理分布、聚类、画像弹窗、商品流向网络、雷达图，适合空间分析和区域洞察。

interactive_dashboard.py
交互式购物行为分析仪表盘。
支持多维筛选（性别、年龄、类别、季节），拖动时间轴观察趋势。
动态展示销量趋势、年龄-类别热力图、客户聚类降维（KMeans+TSNE）、商品推荐相关性网络图、典型消费者画像卡片。
亮点：多维交互、聚类降维、网络推荐、画像展示、YAML配置，适合全局行为分析和个性化探索。

rfm_lifecycle_test.py
客户生命周期与流失预测分析。
基于RFM模型分层客户价值，模拟最近购买、频率、金额，分组打分。
可视化RFM分布，构建流失标签，训练随机森林模型预测流失概率，展示高风险客户列表。
亮点：RFM分层、流失概率预测、交互式可视化，适合客户价值评估和流失预警。


运行代码：
pip install -r requirements.txt
streamlit run rfm_lifecycle_test.py  
streamlit run interactive_dashboard.py
streamlit run geo_advanced_dashboard.py
